{% translate "How a backup moves" %}

{% translate "A successful device backup and a remote copy are related, but they are separate operations." %}

{% translate "1. Collect from device" %} {% translate "The selected driver connects with the effective connection and credential profiles." %}
{% translate "2. Hash and store locally" %} {% translate "The plugin hashes the artifacts. It creates a ConfigRevision according to the backup policy, or links an unchanged run to the latest matching revision." %}
{% translate "3. Replicate new revisions to remote storage" %} {% translate "Each enabled remote storage with automatic copying receives an independent immutable copy of every new revision." %}
{% translate "A temporary remote-storage outage does not change a successful device backup to failed. The Local revision remains valid and the copy can be retried without reconnecting to the device." %}

{% translate "Stored backup download" %}

{% translate "When a native vendor package exists, Download prefers it. Otherwise it returns the primary text or JSON configuration." %}

{% translate "An administrator can require a write-only password in Settings. Downloads are then wrapped in an AES-256 ZIP without changing the stored backup; no usable password means no plaintext fallback." %}
