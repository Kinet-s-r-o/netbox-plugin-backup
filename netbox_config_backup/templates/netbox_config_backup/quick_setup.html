Legacy Telnet connection

This SIAE transport runs only the read-only show running-config command. Telnet does not encrypt the username, password, or configuration in transit, so use it only on a trusted management network or through a protected VPN. First-generation ALFOplus firmware may not support this command and requires a native WebLCT/SCT backup.
