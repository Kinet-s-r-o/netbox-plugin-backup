Native radio backup examples

RipEX2 uses an HTTPS connection profile on port 443. RAy2 and RAy3 use SSH/SFTP on port 22 and need no driver options unless the backup file is stored elsewhere.

SIAE SM-OS automatic backup: use siae_smos_auto. The connection profile selects SSH or Telnet. The driver first validates show running-config. It does not enter configuration mode or create, restore, or activate a native backup. Telnet is unencrypted; restrict it to a trusted management network or protected VPN. A CLI snapshot is not a full restorable .bku or .bak package. First-generation ALFOplus firmware can reject this command and requires its model-specific WebLCT/SCT native backup workflow.
RipEX2 options
{"verify_tls": true, "ca_bundle_path": "/etc/ssl/certs/racom-ca.pem"}
RAy2 / RAy3 options
{"remote_path": "cnf_backup.tgz"}
Ceragon example
{"remote_path": "exports/configuration.zip"}
SIAE native fallback
{"backup_method": "native", "native_model": "alfoplus2", "remote_path": "backup/configuration.bku"}
Ceragon and SIAE paths and export commands depend on firmware. When a command is needed, add "export_command": "vendor documented command" and "allow_export_command": true only after testing it on one device. Without an export command the driver performs only a read-only SFTP download.
